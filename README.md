# 🎙️ Hoshimy Animation Podcast Page

## 🇬🇧 English

### ✨ Overview
This project is a **podcast web page** for *Hoshimy Animation*.  
It includes:
- 🎧 Hero section with the latest episode  
- 📚 Grid layout with podcast episodes  
- 🔍 Sidebar with search, events, and newsletter  
- 🌙/🌞 Theme toggle (dark/light)  
- 🌐 Language switcher (ES/EN)  
- 📩 Newsletter demo with privacy-first message  

---

### 📂 Structure
- **HTML** → header, main (hero + episodes + sidebar), footer  
- **CSS** → light/dark theme, responsive design, grid & cards  
- **JavaScript** → theme toggle, language switch, search, pagination, newsletter demo  

---

### ✅ What you can do
- 🎨 Customize episodes, events, and newsletter backend  
- 🌓 Switch between dark/light theme  
- 🌐 Change language (ES/EN)  
- 🔍 Search across pages  
- 📩 Subscribe to newsletter (demo alert)  

### ❌ What you cannot do
- 🚫 Use `<meta http-equiv="X-Frame-Options">` in HTML (must be server header)  
- 🚫 Expect search/pagination to work on pages without the proper containers (`#episodes-list`, `.articles-container`)  
- 🚫 Remove the language button without protecting JS (otherwise errors occur)  
- 🚫 Load images that don’t exist in `/img/` (cards will appear empty)

## Español

### ✨ Descripción
Este proyecto es una **página web de podcast** para *Hoshimy Animation*.  
Incluye:
- 🎧 Sección hero con el último episodio  
- 📚 Cuadrícula con episodios del podcast  
- 🔍 Barra lateral con buscador, eventos y boletín  
- 🌙/🌞 Interruptor de tema claro/oscuro  
- 🌐 Cambio de idioma (ES/EN)  
- 📩 Demo de boletín con mensaje de privacidad  

---

### 📂 Estructura
- **HTML** → header, main (hero + episodios + sidebar), footer  
- **CSS** → tema claro/oscuro, diseño responsivo, grid y tarjetas  
- **JavaScript** → cambio de tema, idioma, búsqueda, paginación, demo de boletín  

---

### ✅ Lo que sí puedes hacer
- 🎨 Personalizar episodios, eventos y backend del boletín  
- 🌓 Cambiar entre tema claro/oscuro  
- 🌐 Alternar idioma (ES/EN)  
- 🔍 Buscar en páginas  
- 📩 Suscribirte al boletín (demo con alerta)  

### ❌ Lo que no puedes hacer
- 🚫 Usar `<meta http-equiv="X-Frame-Options">` en HTML (debe ser encabezado del servidor)  
- 🚫 Esperar que búsqueda/paginación funcionen en páginas sin los contenedores (`#episodes-list`, `.articles-container`)  
- 🚫 Quitar el botón de idioma sin proteger el JS (si no, da error)  
- 🚫 Cargar imágenes que no existen en `/img/` (las tarjetas se verán vacías)
